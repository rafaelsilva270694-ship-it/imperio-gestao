# IMPÉRIO GESTÃO

Projeto inicial Flutter do aplicativo de vendas e estoque.

## Identificador sugerido
com.imperiodobrilho.gestao

## Próximas etapas
1. Instalar Flutter e Android Studio em um computador.
2. Executar `flutter create .` dentro desta pasta para gerar as pastas Android/iOS.
3. Configurar Firebase (Authentication + Firestore) para login, vendedores, clientes, vendas e estoque.
4. Implementar as regras de negócio, incluindo o limite de até 2 compras com dívida.
5. Testar no Android.
6. Gerar o AAB com `flutter build appbundle --release`.
7. Enviar o AAB ao Google Play Console.

Este arquivo é uma base inicial do projeto; ele ainda não é o AAB final nem contém a configuração de produção do Firebase.
